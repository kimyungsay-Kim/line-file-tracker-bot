# บอทติดตามไฟล์งาน/ข้อความที่แท็คในกลุ่ม LINE

บอทนี้ทำงาน 2 โหมดต่อกลุ่ม:
- **โหมดส่งไฟล์** (ค่าเริ่มต้น สำหรับกลุ่มที่ไม่ได้ระบุไว้เป็น PM mode) — นับเฉพาะกรณีมีคนส่ง **ไฟล์ + แท็คคุณ (หรือแอดมิน)** จับคู่ให้ไม่ว่าไฟล์จะมาก่อนหรือหลังข้อความแท็ค (ภายใน 30 นาที ปรับได้)
- **โหมด PM** (สำหรับกลุ่มที่แจ้งงาน/สั่งงาน ไม่จำเป็นต้องมีไฟล์) — แค่มีคนแท็คคุณหรือแอดมิน ก็บันทึกข้อความไว้สรุปให้ ไม่ต้องมีไฟล์แนบ

ดูสรุปได้ 2 ทาง:
1. พิมพ์ `สรุป` คุยกับบอทแบบ 1:1 เมื่อไหร่ก็ได้
2. บอทส่งสรุปให้อัตโนมัติทุกวัน ตามเวลาที่ตั้งไว้ (ค่าเริ่มต้น 18:00 น.)

ทั้งไฟล์และข้อความที่ถูกแท็ค (โหมด PM) มีสถานะ "ปิด" เหมือนกัน — ใช้คำสั่ง `โหลดแล้ว` (หรือ `✅`) ปิดได้ทั้งสองแบบ ไม่ต้องรอให้เป็นไฟล์เท่านั้น

นอกจากนี้ทุกเช้า (ค่าเริ่มต้น 08:00 น.) บอทจะเช็คว่ามีรายการจาก**วันก่อนหน้า**ที่ยังไม่ได้ปิดสถานะค้างอยู่ไหม (ทั้งไฟล์และข้อความที่ถูกแท็ค) ถ้ามี จะส่งแจ้งเตือนแยกต่างหากอัตโนมัติ โดยแสดงรายการที่ค้างเป็น**ตัวอักษรสีแดง** ให้เห็นชัดเจน (ถ้าไม่มีรายการค้าง จะไม่ส่งอะไรเลย)

**สรุปแบบร่วมกัน**: ถ้าใน `TAGGED_USER_IDS` มีมากกว่า 1 คน (เช่น คุณ + แอดมิน) ทุกคนจะเห็น "สรุป" ชุดเดียวกันเสมอ (ทั้งแบบพิมพ์ถามเองและแบบส่งอัตโนมัติทุกวัน) ไม่ว่าข้อความนั้นจะแท็คใครในลิสต์ก็ตาม ส่วนสถานะปิด (✅/🔲) ของแต่ละรายการ เป็นข้อมูลที่ใช้ร่วมกัน — ใครปิดสถานะไปแล้ว จะเห็นเป็น ✅ เหมือนกันทุกคน พร้อมบอกด้วยว่า **ใครเป็นคนปิด** (เช่น "ปิดโดย Tok")

## ขั้นตอนตั้งค่า

### 1. ไปเอา Channel Access Token
1. เข้า [LINE Developers Console](https://developers.line.biz/console/)
2. เลือก Provider / Channel ของ OA ที่มีอยู่แล้ว
3. แท็บ **Messaging API** → เลื่อนลงไปที่ **Channel access token** → กด **Issue** (ถ้ายังไม่เคยออก) แล้วคัดลอกเก็บไว้
4. แท็บ **Basic settings** → คัดลอก **Channel secret** เก็บไว้ด้วย

### 2. ปิด auto-reply เดิมของ LINE OA
ในหน้า [LINE Official Account Manager](https://manager.line.biz/) → ตั้งค่า → การตอบกลับอัตโนมัติ:
- ปิด "ข้อความต้อนรับ" และ "ข้อความตอบกลับอัตโนมัติ" (ไม่งั้นจะชนกับบอท)
- เปิด **Webhook** ให้เป็น "ใช้งาน" (จะมาตั้ง URL ในขั้นตอนที่ 4)

### 3. Deploy ขึ้น Render (ฟรี)
1. สมัคร/ล็อกอิน [render.com](https://render.com) ด้วย GitHub
2. อัปโหลดโฟลเดอร์นี้ขึ้น repo GitHub ใหม่ (หรือให้ผมช่วย push ให้ก็ได้ถ้าต่อ GitHub ไว้)
3. ใน Render กด **New → Blueprint** แล้วเลือก repo นี้ (จะอ่าน `render.yaml` ให้อัตโนมัติ)
4. ตอนตั้งค่า ใส่ค่า environment variables เท่าที่มีตอนนี้ (ที่เหลือมาใส่ทีหลังได้ใน Environment tab):
   - `LINE_CHANNEL_SECRET` = ค่าจากขั้นตอนที่ 1
   - `LINE_CHANNEL_ACCESS_TOKEN` = ค่าจากขั้นตอนที่ 1
   - `OWNER_USER_ID`, `TAGGED_USER_IDS`, `PM_MODE_GROUP_IDS` = เว้นว่างไว้ก่อน (ใส่ทีหลังในขั้นตอนที่ 6-7)
5. กด Deploy รอจนขึ้น "Live" แล้วคัดลอก URL ของบริการ (เช่น `https://line-file-tracker-bot.onrender.com`)

### 4. ตั้ง Webhook URL ใน LINE
กลับไปที่ LINE Developers Console → แท็บ Messaging API → **Webhook URL** → ใส่:
```
https://<ชื่อบริการของคุณ>.onrender.com/callback
```
กด **Verify** ให้ขึ้นสำเร็จ แล้วเปิด toggle "Use webhook"

### 5. เชิญบอทเข้าทุกกลุ่ม (ทั้ง 3 กลุ่ม)
เพิ่ม LINE OA ของคุณเป็นสมาชิกในแต่ละกลุ่ม และตรวจสอบว่าใน **Messaging API settings** เปิด "Allow bot to join group chats" แล้ว

### 6. หา User ID ของคุณและแอดมิน → ตั้งค่า OWNER_USER_ID และ TAGGED_USER_IDS
1. ให้ทั้งคุณและแอดมินแอดบอทเป็นเพื่อน 1:1 แล้วพิมพ์ `id` คุยกับบอท
2. บอทจะตอบ user_id กลับมาแต่ละคน (เช่น `U1234567890abcdef...`)
3. ใน Render → Environment ตั้งค่า:
   - `OWNER_USER_ID` = user_id ของคุณ (คนที่จะได้รับสรุปประจำวัน)
   - `TAGGED_USER_IDS` = user_id ของคุณ,user_id ของแอดมิน (คั่นด้วยจุลภาค ไม่เว้นวรรค) — ใครก็ตามในลิสต์นี้ ถ้าถูกแท็คในกลุ่ม จะถูกนับ

### 7. หา Group ID ของกลุ่ม "PM" → ตั้งค่า PM_MODE_GROUP_IDS
1. ในกลุ่ม Project Management Team พิมพ์ `groupid` (พิมพ์ในกลุ่มได้เลย ใครพิมพ์ก็ได้)
2. บอทจะตอบ group_id ของกลุ่มนั้นกลับมาในกลุ่ม
3. เอาค่านั้นไปใส่ใน Render → Environment → `PM_MODE_GROUP_IDS`
   - ถ้ามีหลายกลุ่มแบบ PM mode คั่นด้วยจุลภาคได้ เช่น `Cxxxx1,Cxxxx2`
   - กลุ่มที่ไม่ได้ใส่ในนี้ (2 กลุ่มส่งไฟล์) จะเป็นโหมดไฟล์+แท็คตามปกติ ไม่ต้องตั้งอะไรเพิ่ม

บันทึก Environment แต่ละครั้งจะ redeploy อัตโนมัติ

เท่านี้ก็ใช้งานได้ครับ ลองทดสอบแล้วพิมพ์ `สรุป` คุยกับบอท 1:1 ดู

## ปรับแต่งได้
ตัวแปรใน Render → Environment:
- `DIGEST_HOUR`, `DIGEST_MINUTE` — เวลาสรุปอัตโนมัติประจำวัน (24 ชม., เวลาไทย) ค่าเริ่มต้น 18:00
- `OVERDUE_HOUR`, `OVERDUE_MINUTE` — เวลาแจ้งเตือนไฟล์ค้างจากวันก่อนหน้าทุกเช้า (24 ชม., เวลาไทย) ค่าเริ่มต้น 08:00 — ถ้าไม่มีไฟล์ค้างจะไม่ส่งอะไรเลย
- `TAG_LOOKBACK_MINUTES` — ไฟล์กับข้อความแท็คห่างกันกี่นาทีถึงจะนับว่าเกี่ยวข้องกัน (นับได้ทั้งแท็คก่อน/หลังไฟล์) ค่าเริ่มต้น 30 นาที
- `TAGGED_USER_IDS` — รายชื่อ user_id ที่นับว่า "ถูกแท็ค" (คั่นด้วยจุลภาค)
- `PM_MODE_GROUP_IDS` — รายชื่อ group_id ที่ใช้โหมด PM (ไม่ต้องมีไฟล์)
- `INSPECTION_TARGET_GROUP_ID` — group_id ของกลุ่มที่จะโพสต์รายการเอกสารตรวจสอบ (ดูหัวข้อ "รายการเอกสารตรวจสอบ" ด้านบน)
- `TURSO_DATABASE_URL`, `TURSO_AUTH_TOKEN` — ที่อยู่และคีย์เข้าถึงฐานข้อมูล Turso (ดูหัวข้อ "ฐานข้อมูล" ด้านล่าง) จำเป็นต้องตั้งค่า ไม่งั้นบอทจะสตาร์ทไม่ขึ้น

## ฐานข้อมูล
บอทเก็บข้อมูลทั้งหมด (ไฟล์ที่ถูกแท็ค สถานะโหลดแล้ว) ไว้ใน [Turso](https://turso.tech) ซึ่งเป็นฐานข้อมูล SQLite บนคลาวด์แบบฟรี **ข้อมูลจะไม่หายเวลา deploy โค้ดใหม่** (ต่างจากไฟล์ฐานข้อมูลในเครื่อง Render ที่หายทุกครั้งที่ deploy เพราะแพลนฟรีไม่มี persistent disk)

วิธีตั้งค่า:
1. สมัคร/ล็อกอิน [turso.tech](https://turso.tech) แล้วสร้างฐานข้อมูลใหม่
2. ในหน้าฐานข้อมูล ไปที่ส่วน "Connect" คัดลอก **Database URL** (ขึ้นต้นด้วย `libsql://...`) และสร้าง **Auth Token**
3. นำสองค่านี้ไปตั้งใน Render → Environment เป็น `TURSO_DATABASE_URL` และ `TURSO_AUTH_TOKEN`

## คำสั่งที่ใช้ได้
**ในแชท 1:1 กับบอท:**
- `สรุป` — ดูสรุปวันนี้ (แยกตามกลุ่ม แยกตามคนส่ง)
- `โหลดแล้ว` (หรือ `✅`/`👍`) — ปิดสถานะรายการค้างทั้งหมด (ทั้งไฟล์ที่ยังไม่โหลด **และ** ข้อความที่ถูกแท็คที่ยังไม่ปิด)
- `โหลดแล้ว <ชื่อคน>` (หรือ `✅ <ชื่อคน>`) — ปิดสถานะเฉพาะของคนนั้น ไม่ว่าจะเป็นไฟล์หรือข้อความ
- `✅ REQ` / `✅ BIM` / `✅ PM` — ปิดสถานะเฉพาะกลุ่มนั้น (REQ = FTC-AIH_Req't Document, BIM = FTC_AIH-BIM&Shop Dwg., PM = FTC_AIH_Project Management Team) พิมพ์ชื่อกลุ่มเต็มหรือบางส่วนก็ได้ ไม่ต้องสนขีด/เว้นวรรค/ตัวพิมพ์ใหญ่เล็ก
- `✅ PM <ชื่อคน>` — ปิดเฉพาะคนนั้นในกลุ่มนั้น
- ในการ์ดสรุป มีปุ่ม `✅ ปิดทั้งกลุ่ม` ข้างชื่อกลุ่ม และ `✅ ปิด` ข้างชื่อคน กดแทนพิมพ์ได้เลย
- `ย้อนกลับ` (หรือ `เลิกทำ`/`undo`) — เปิดสถานะคืนเฉพาะชุดที่ตัวเองปิดไปล่าสุด กดซ้ำได้เพื่อย้อนไปทีละชุด
- ทุกครั้งที่ปิด จะบันทึก "ใคร · ปิดแบบไหน" (เช่น `Kim · ปิด ทั้งกลุ่ม PM`) ไว้ในช่อง "ปิดโดย"/"โหลดโดย" ของสรุปและรายงานรายวัน
- เพิ่ม/แก้ชื่อย่อกลุ่มได้ด้วย env `GROUP_ALIASES` เป็น JSON เช่น `{"QA": "QA Inspection"}`
- `id` — ดู user_id ของตัวเอง (ใช้ตอนตั้งค่า)
- วางรายการเอกสาร (ดูหัวข้อ "รายการเอกสารตรวจสอบ (Inspection)" ด้านล่าง) — ดูตัวอย่าง (Carousel) แล้วพิมพ์ `ส่ง`/`ยืนยัน` เพื่อโพสต์เข้ากลุ่ม หรือ `ยกเลิก`
- `รายงาน` — ขอลิงก์ดาวน์โหลดรายงานข้อมูลวันนี้เป็นไฟล์ (ดูหัวข้อ "รายงานข้อมูลรายวัน (CSV)" ด้านล่าง)
- `คำตอบ` — ดูเอกสารที่โพสต์ใน 14 วันล่าสุด พร้อมจำนวนคำตอบ (ฉบับที่ยังไม่มีคำตอบขึ้นก่อน)
- `คำตอบ AR-337` — ดูคำตอบทั้งหมดของเอกสารนั้น
- `ติดตาม` — ดูตัวอย่างข้อความติดตามคำตอบที่จะส่งเข้ากลุ่ม
- `ส่งติดตาม` — ส่งข้อความติดตามคำตอบเข้ากลุ่มทันที (ไม่ต้องรอเวลาอัตโนมัติ)
- `บัดดี้` — ดูทีมผู้รับผิดชอบตอบเอกสารทั้งหมด · `ลบบัดดี้ EE-A` — ลบทีมนั้น
- `ปิดเอกสาร AR-337` — ปิดเอกสารเอง (ไม่อยู่ในรายการติดตามอีก) · `เปิดเอกสาร AR-337` — เปิดคืน

**ในกลุ่ม:**
- `groupid` — ดู group_id ของกลุ่มนั้น (ใช้ตอนตั้งค่า)
- `AR-337 <ข้อความ>` — ตอบกลับเอกสารที่เคยโพสต์ (ดูหัวข้อ "ตอบกลับเอกสาร" ด้านล่าง)

## ตอบกลับเอกสาร
ทุกเอกสารที่โพสต์เข้ากลุ่มด้วย `ส่ง` จะถูกบันทึกไว้ และทีมพิมพ์คำตอบได้หลายข้อความต่อเอกสาร 2 ทาง:
1. **ในกลุ่ม** — พิมพ์รหัสเอกสารตามด้วยข้อความ เช่น `AR-337 ตรวจแล้ว เหลือแก้รอยต่อฝ้า` (รับ `ar 337: ...`, `AR-337 - ...` ได้ด้วย) บอทจะเก็บเงียบๆ ไม่ตอบกลับในกลุ่ม นับเฉพาะรหัสที่เคยโพสต์จริง
2. **ปุ่ม "💬 ตอบกลับเอกสารนี้"** ใต้เอกสารแต่ละฉบับในการ์ด — เปิดหน้าเล็ก (LIFF) ในแอป LINE แสดงคำตอบทั้งหมดพร้อมชื่อและเวลา และช่องพิมพ์คำตอบ

ไม่มีการแจ้งเตือนเมื่อมีคำตอบใหม่ (ประหยัดโควตาข้อความ) — เช็กด้วยคำสั่ง `คำตอบ` หรือดูบรรทัด "เอกสารที่ยังไม่มีคำตอบ" ท้ายข้อความรายงานประจำวัน

**ตั้งค่าปุ่มตอบกลับ (LIFF)** — ถ้ายังไม่ตั้ง การ์ดจะไม่มีปุ่ม แต่การพิมพ์ในกลุ่มยังใช้ได้:
1. LINE Developers Console → Provider เดิม → Create a new channel → **LINE Login**
2. ในแท็บ LIFF → Add: Size = **Tall**, Endpoint URL = `https://line-file-tracker-bot.onrender.com/liff/reply`, Scopes = `openid` + `profile`
3. ตั้ง env บน Render: `LIFF_ID` = LIFF ID ที่ได้ (เช่น `2001234567-AbCdEfGh`), `LINE_LOGIN_CHANNEL_ID` = Channel ID ของ LINE Login channel นั้น
4. Publish channel (เปลี่ยนจาก Developing เป็น Published) ไม่งั้นคนอื่นนอกจากผู้สร้างจะเปิดไม่ได้

รายการยาวจะถูกแบ่งเป็นการ์ดหลายใบเรียงต่อกันในแนวตั้งอัตโนมัติ (สูงสุด 3 ใบ) เพราะ LINE รับการ์ดได้ไม่เกิน 30 KB ต่อใบ (ประมาณ 14–16 เอกสาร)

- ปรับได้ด้วย env: `REMIND_HOUR`, `REMIND_MINUTE`, `REMIND_DAYS_OF_WEEK` (เช่น `mon-fri`), `REMIND_WINDOW_DAYS`, `REMIND_LATE_DAYS`, `REMIND_MENTION_TEXT`

## บัดดี้ผู้รับผิดชอบตอบเอกสาร
ตั้งในกลุ่ม (เฉพาะเจ้าของบอท, ต้องเลือกชื่อจากรายชื่อที่ LINE เด้งขึ้นมา) คำสั่งละ 1 ทีม — บอทยืนยันทางแชท 1:1 ไม่ตอบในกลุ่ม:
```
ตั้งบัดดี้ AR,ST EE-A @คน1 @คน2
ตั้งบัดดี้ AR,ST EE-B @คน3 @คน4
ตั้งบัดดี้ AR,ST AC @คน5 @คน6
ตั้งบัดดี้ AR,ST SN/FP @คน7 @คน8
```
- เอกสารหมวด AR/ST ต้องได้คำตอบจาก **ทุกระบบ** (EE, AC, SN/FP) ในแต่ละทีม คนใดคนหนึ่งตอบก็นับทั้งทีม
- ทีมชื่อ `ระบบ-ตึก` (EE-A, EE-B) แยกตามตึก: บอทหาคำว่า "อาคาร A / ตึก B / Building A / Zone B" ในชื่อเรื่อง เจอตึกเดียว → รอทีมตึกนั้น, ไม่เจอหรือเจอทั้งสองตึก → ทีมไหนตอบก่อนก็นับ
- คนนอกทีมตอบ → บันทึกไว้แต่ไม่นับ และแจ้งเจ้าของบอททาง 1:1 ให้ตรวจ แล้วปิดเองด้วย `ปิดเอกสาร`
- ใช้ user ID ของ LINE: เปลี่ยนชื่อ LINE ได้ไม่กระทบ ถ้าผู้รับผิดชอบออกจากกลุ่ม บอทแท็ก @All แทนและแจ้งให้ตั้งคนใหม่
- **ทีมที่ตอบแอดมินทางส่วนตัว (เช่น AC)** — แอดมินบันทึกแทนในแชท 1:1 กับบอท:
  - `ตอบแล้ว AR-325 RIH-I02330` — ใส่รหัสหรือเลขที่เอกสาร (ท้ายเลขก็ได้ เช่น `02330`) ได้หลายฉบับ ไม่ใส่ชื่อทีม = AC (เปลี่ยนได้ด้วย env `MANUAL_ANSWER_DEFAULT_TEAM`)
  - `AC ตอบครบแล้ว` — ทุกฉบับที่ยังรอทีม AC
  - `AC ยกเลิกตอบแล้ว AR-325` — ยกเลิกถ้าบันทึกผิด
  - ใช้กับทีมอื่นได้ด้วย เช่น `SN/FP ตอบแล้ว AR-325`
- หมวดที่ไม่ได้ตั้งทีม ใช้กติกาเดิม (มีคำตอบอย่างน้อย 1 ข้อความ = ตอบแล้ว, แท็ก @All)

## รายการเอกสารตรวจสอบ (Inspection)
ใช้คู่กับ Claude ใน Chrome: ให้ Claude หาเอกสารจาก Site Around (กรองตามวันที่/ผู้ส่ง Admin-PB) แล้วสรุปมาให้ จากนั้นก๊อปข้อความที่สรุปมาวางในแชท 1:1 กับบอทนี้ได้เลย (ไม่ต้องพิมพ์คำสั่งอะไรก่อน บอทจะรู้จักรูปแบบเองจากเครื่องหมาย `|`)

**รูปแบบที่วาง** หนึ่งบรรทัดต่อหนึ่งเอกสาร คั่นด้วย `|` อย่างน้อย 4 ช่อง (ช่องที่ 5 ขึ้นไปเป็นวันที่/หมายเหตุเพิ่มเติมก็ได้ เช่น วันที่เทคอนกรีต/ก่อ/ฉาบ):
```
code|เลขที่เอกสาร|เรื่อง|วันที่ส่งเอกสารเข้าระบบ[|วันที่เทคอนกรีต/ก่อ/ฉาบ/อื่นๆ]
```
ตัวอย่าง:
```
AR-329|RIH-QA-0123|ขออนุมัติวัสดุ Shop Drawing|23/10/2026
AR-330|RIH-QA-0124|ขออนุมัติแบบ RFI|23/10/2026|วันที่เทคอนกรีต 24/10/2026
```
บอทจะตอบกลับเป็นข้อความหัวข้อแจ้งจำนวนเอกสาร ตามด้วย Flex message (การ์ดเดียว หรือหลายใบเรียงต่อกันถ้ารายการยาว) แสดงทุกเอกสารเรียงกันเป็นแนวตั้ง (ไม่ใช่ Carousel ที่ต้องปัดซ้าย-ขวา) แต่ละเอกสารมีไอคอน/สีแยกแต่ละช่อง ให้ตรวจดูก่อน:
- พิมพ์ `ส่ง` หรือ `ยืนยัน` — โพสต์เข้ากลุ่มที่ตั้งไว้ใน `INSPECTION_TARGET_GROUP_ID` (ข้อความหัวข้อ + Flex message + แท็ค @All)
- พิมพ์ `ยกเลิก` — ยกเลิกรายการที่รอไว้ ไม่โพสต์อะไร

ต้องตั้งค่า environment variable `INSPECTION_TARGET_GROUP_ID` เป็น group_id ของกลุ่มปลายทาง (ใช้คำสั่ง `groupid` ในกลุ่มนั้นเพื่อหาค่านี้) ไม่งั้นตอนพิมพ์ `ส่ง` บอทจะแจ้งว่ายังไม่ได้ตั้งค่า

### แยก Inspector / Assignee (เอกสารรับมอบพื้นที่)
บอทแยกให้อัตโนมัติจากรหัส Site Around: `RIH-R…`/`AIH-R…` = Assignee, อื่นๆ (`RIH-I…`) = Inspector วางปนกันในครั้งเดียวได้ ถ้าต้องการบังคับเอง (ชนะการแยกอัตโนมัติ) ใช้ `A|`/`I|` หน้าบรรทัด:
```
A|LT-216|RIH-R01155|ขอส่งพื้นที่ห้องศูนย์สั่งการดับเพลิง ชั้น G อาคาร B|24/10/2026|ไม่มีระบุวันที่ดำเนินงาน
```
หรือขึ้นบรรทัดหัว `#ASSIGNEE` (หรือ `#A`, `รับมอบพื้นที่`) แล้วบรรทัดถัดไปทั้งหมดเป็น Assignee จนเจอ `#INSPECTOR` / `#I`

ตอน `ส่ง` บอทโพสต์แยก 2 ชุด (Inspector ก่อน):

| | Inspector | Assignee |
|---|---|---|
| หัวข้อ | แจ้งข้อมูลเอกสาร Request จาก บมจ.พรีบิลท์ (PB) | แจ้งรายการเอกสารรับมอบพื้นที่จาก PB |
| รหัส | `PB-291069-1` (รหัสรอบแจ้ง) | `AS-291069-1` (รหัสแจ้ง, นับแยก) — เปลี่ยน prefix ด้วย `ASSIGNEE_BATCH_PREFIX` |
| สีแถบ | ส้มแดง (เร่งด่วน) | น้ำเงิน |
| ช่องท้าย | วันที่เทคอนกรีต/ก่อ/ฉาบ/อื่นๆ | รอแนบรูป / จำนวนวันที่ค้าง (นับจากวันส่งเข้าระบบ, แดงเมื่อ ≥ `REMIND_LATE_DAYS`) |
| แท็ก | @All | CO คนเดียว (ถ้ายังไม่ตั้ง จะแท็ก @All และเตือน) |

**ตั้ง CO:** พิมพ์ในกลุ่ม `ตั้งผู้รับผิดชอบ CO @ชื่อ` (เจ้าของบอทเท่านั้น ผลแจ้งในแชท 1:1) · ดูได้ด้วย `ผู้รับผิดชอบ` / `บัดดี้` ในแชท 1:1 · การติดตามรายวันก็แท็ก CO สำหรับเอกสาร Assignee ที่ยังไม่ได้ตอบ

## สรุปในแชท (สรุป / ส่งอัตโนมัติทุกวัน)
สรุปที่ตอบกลับคำสั่ง `สรุป` และที่ส่งอัตโนมัติทุกวันตอนนี้**แสดงเฉพาะไฟล์/ข้อความที่ยังไม่ได้ปิดสถานะเท่านั้น** — รายการที่ปิดสถานะ (`โหลดแล้ว`/`✅`) ไปแล้วจะไม่โผล่มาให้รกตาอีก (รวมถึงคนที่ปิดสถานะครบหมดแล้ว ก็จะไม่มีชื่อโผล่มาในสรุปนั้นเลย) — ใช้ได้ทั้งกับไฟล์ที่ยังไม่โหลดและข้อความที่ถูกแท็คที่ยังไม่ปิด รายการที่ยังไม่ปิดจากวันก่อนหน้าจะถูก**ยกยอดมาแสดงต่อ**จนกว่าจะปิดสถานะ

## รายงานข้อมูลรายวัน (Excel จัดสีสวย / CSV)
นอกจากสรุปในแชท ยังมีรายงานแบบไฟล์ให้ดึงไปเก็บเป็นข้อมูลหลังบ้านได้ ข้อมูลในรายงานของแต่ละวันจะ**รวมรายการค้างจากวันก่อนหน้ามาแสดงด้วย** (ทั้งไฟล์และข้อความที่ถูกแท็ค — คอลัมน์ "หมายเหตุ" จะบอกว่า "ใหม่วันนี้" หรือ "ยกยอดจากวันก่อน") ต่างจากสรุปในแชทตรงที่รายงานจะแสดง**ทุกรายการของวันนั้น รวมทั้งที่ปิดสถานะแล้วด้วย** (เป็นบันทึกประวัติแบบเต็ม ไม่ใช่แค่รายการค้าง — คอลัมน์ "สถานะ" จะบอกว่า "ปิดแล้ว" หรือ "ยังไม่ปิด")

รายงานหลักเป็นไฟล์ **Excel (.xlsx)** จัดรูปแบบสีสันพร้อมเปิดดูได้เลย — มีแถบหัวเรื่อง, สรุปตัวเลข (ทั้งหมด/ปิดแล้ว/ยังไม่ปิด), แบ่งบล็อกตามกลุ่ม (แถบสีเขียวคั่นแต่ละกลุ่ม), คอลัมน์ "สถานะ" ไฮไลท์สีเขียว/แดงให้เห็นชัด, สลับแถบสีอ่านง่าย, ล็อกหัวตารางและมี filter ให้พร้อม ถ้าต้องการไฟล์ CSV ดิบไปประมวลผลต่อก็ยังมีให้เหมือนเดิม

ถัดจากคอลัมน์ "สถานะ" มีอีก 2 คอลัมน์พื้นหลังสีเหลือง (เฉพาะในไฟล์ Excel เท่านั้น ไม่มีในไฟล์ CSV) สำหรับใช้ตรวจทวนด้วยตัวเองหลังดาวน์โหลด:
- **✔️ Recheck** — กล่องสีเหลืองเด่นๆ เหมือนปุ่มติ๊ก เริ่มต้นเป็น ☐ (สีเทา พื้นเหลืองอ่อน) คลิกที่ช่องแล้วกดลูกศร dropdown เลือก **✓** เพื่อติ๊ก (ช่องจะเปลี่ยนเป็นสีเขียวทันที) หรือเลือก **☐** เพื่อยกเลิกติ๊ก — สลับไปมาได้ด้วยการเลือกจาก dropdown ทีละครั้ง
- **ผลตรวจสอบ** — คอลัมน์สูตรอัตโนมัติ เทียบว่าที่ติ๊กใน Recheck กับคอลัมน์ "สถานะ" ตรงกันหรือไม่ ถ้าติ๊ก ✔ และสถานะ "ปิดแล้ว" (หรือไม่ติ๊กและสถานะ "ยังไม่ปิด") จะโชว์ **"ตรงกัน"** (เขียว) ไม่งั้นโชว์ **"ไม่ตรงกัน"** (แดง) — คำนวณสดทันทีที่ติ๊ก ไม่ต้องกดอะไรเพิ่ม

หมายเหตุ: ช่อง Recheck ไม่ได้บันทึกกลับเข้าระบบ (เป็นแค่สำเนาที่ดาวน์โหลดไปตรวจเองแต่ละครั้ง) ถ้าโหลดรายงานของวันเดิมซ้ำ ช่อง Recheck จะเริ่มใหม่ว่างทุกครั้ง

วิธีดึง:
- พิมพ์ `รายงาน` คุยกับบอท 1:1 — บอทจะตอบลิงก์ดาวน์โหลดทั้งแบบ Excel และ CSV ของวันนี้กลับมา
- หรือเข้าลิงก์ตรงๆ ได้เลย:
  - Excel: `https://<ชื่อบริการ>.onrender.com/report/daily.xlsx?date=YYYY-MM-DD`
  - CSV: `https://<ชื่อบริการ>.onrender.com/report/daily.csv?date=YYYY-MM-DD`
  - (ไม่ใส่ `date` จะได้ของวันนี้)
- รายงานของวันนี้ (แบบ Excel) จะถูกส่งเป็นลิงก์แนบท้ายสรุปอัตโนมัติประจำวันด้วย (ถ้าตั้งค่า `SERVICE_BASE_URL` ไว้)

ตั้งค่าเพิ่มเติม (ไม่บังคับ):
- `SERVICE_BASE_URL` — URL ของบริการนี้เอง (เช่น `https://line-file-tracker-bot.onrender.com`) จำเป็นสำหรับให้สรุปอัตโนมัติประจำวันแนบลิงก์รายงานมาด้วย (คำสั่ง `รายงาน` ที่พิมพ์เองไม่ต้องตั้งค่านี้ก็ใช้ได้)
- `REPORT_ACCESS_KEY` — ถ้าตั้งค่าไว้ ต้องเข้าลิงก์พร้อม `&key=...` ต่อท้ายถึงจะดูได้ (กันคนนอกเดาลิงก์แล้วเข้าดูข้อมูล) ถ้าไม่ตั้งค่า ใครมีลิงก์ก็เข้าดูได้เลย

## ข้อจำกัดที่ควรรู้
- ข้อมูลเก็บถาวรใน Turso แล้ว deploy โค้ดใหม่ไม่ล้างข้อมูล (ต่างจากก่อนหน้านี้ที่ใช้ไฟล์ในเครื่อง Render)
- Render free tier จะ sleep เมื่อไม่มีการใช้งาน ~15 นาที คำขอ webhook แรกหลัง sleep อาจช้าไปสองสามวินาที (ปกติไม่กระทบ เพราะ LINE จะ retry เอง) แต่ถ้าอยากให้ไวตลอดเวลา ค่อยอัปเป็นแพลนเสียเงินทีหลังได้
- การแท็คต้อง "เลือกชื่อจากป๊อปอัพ" ของ LINE จริงๆ (ไม่ใช่พิมพ์ @ชื่อ เฉยๆ) ถึงจะมีข้อมูล user_id ให้บอทตรวจจับได้
- บอทจะไม่เห็นอีโมจิรีแอคชัน (❤️/👍) ที่กดใส่ข้อความคนอื่นในกลุ่ม เพราะ LINE API ไม่ส่งข้อมูลนี้มาให้บอทรับรู้ (ใช้คำสั่ง "โหลดแล้ว" แทนได้)
